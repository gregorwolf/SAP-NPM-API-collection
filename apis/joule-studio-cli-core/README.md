# @sap/joule-studio-cli-core

Core library for the [Joule Studio Command Line Interface](https://www.npmjs.com/package/@sap/joule-studio-cli).

This package provides shared utilities, API clients, and base functionality used internally by `@sap/joule-studio-cli`. It is not intended to be installed or used independently.

## Installation

This package is automatically installed as a dependency of `@sap/joule-studio-cli`.
